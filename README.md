# Исследование
## Исследование 1. Что находится внутри int

При написание цифры 1:
01-00-00-00 байты
---
При написание цифры 256:
00-01-00-00 байты
---
При написание цифры 65536:
00-00-01-00 байты

Ответы на вопросы:
1. Можно сказать, что процессору выгоднее тратить немного больше память, чтобы работать быстрее.
2. Оно не помещается в 1 байт, и для его записи активируется второй байт.
3. Для него теперь активируется 3 байт, потому что не вмещается в два байта.

## Исследование 2. Почему порядок байтов имеет значение

Little-endian: True
Байты числа: 78-56-34-12
Младший байт хранится первым

## Исследование 3. Число и текст

При запуске с разным кол-во символов, мы получаем разное значение байт. Это связанно с тем, что Латинские буквы занимают 1 байт. А Кириллица занимает 2 байта.

## Исследование 4. Английская и русская буква

A(англ): 41 (1байт)
А(русс): D0-90 (2байта)

Для обратного преобразование мы указываем UTF-8, чтобы еще раз указать в какой кодировки были записаны байты, потому что они такую информацию не хранят.
